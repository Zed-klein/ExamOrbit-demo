# ExamOrbit · 考点雷达

> 考试出行规划的纯前端工具：定位考点、查看周边设施、比较住宿与通勤路线，并结合考试时间和天气安排出发。

[在线体验](https://zed-klein.github.io/ExamOrbit-demo/) · [GitHub 仓库](https://github.com/Zed-klein/ExamOrbit-demo)

地图上的“考点”不只是一个坐标。实际到场还会受到校区入口、道路绕行、居住位置、交通方式和天气影响。ExamOrbit 将这些信息串成一个可操作的规划流程；也提供对话入口，帮助完成同一套工作流。

## 功能

| 界面 | 主要能力 |
| --- | --- |
| **① 考点选择** | 按省市区搜索学校或校区、地图选点；可选填酒店或住址作为起点；设置考试名称、日期及时间。 |
| **② 周边设施** | 查看考点周边的打印店、文具店、便利店、药店、派出所、医院、停车场及餐饮等设施。 |
| **③ 行程可视化** | 展示等时圈与服务点图层，比较住宿和步行、骑行、公交、驾车等出行方式。 |
| **④ 路线规划** | 查看住处或选定住宿到考点的路线、耗时、分段指引和沿线便利设施，并切换出行方式。 |
| **⑤ AI 辅助出行** | 通过对话定位考点、查找起点和服务点、切换路线及打开天气推演；无 LLM 时使用本地规则引擎。 |

**天气推演**支持调整出发时间，结合逐小时天气展示通勤风险，并在近期恶劣天气下提示更稳妥的出行方案。天气类型覆盖雨、雪、雷暴、雾；沙尘识别依赖空气质量数据。

前四个界面可以直接手动操作。AI 辅助出行是独立的对话入口，调用相同的地图与规划能力，不是使用这些功能的前提。

## 在线体验与本地运行

直接打开 **[在线演示](https://zed-klein.github.io/ExamOrbit-demo/)**。页面内置浙江大学紫金港校区的案例，也支持输入自己的考点。

本项目没有构建步骤或后端依赖。本地运行：

```bash
git clone https://github.com/Zed-klein/ExamOrbit-demo.git
cd ExamOrbit-demo
python3 -m http.server 8899
```

访问 `http://127.0.0.1:8899/`。请从包含 `index.html`、`config/`、`src/` 和 `data/` 的目录启动静态服务器；如果这些文件位于子目录，则进入该子目录后启动。

使用 `localhost` 或 HTTPS 可以减少浏览器定位及跨域调用的限制。直接双击 `index.html` 可查看部分内容，但 `file://` 环境可能阻止定位、地图请求或模型接口访问。

### 如何使用

1. 在“考点选择”搜索学校或使用地图选点；也可点击页面内的浙江大学案例快速体验。
2. 按需填写居住点，设置考试日期和开考时间，点击“开始检索”。
3. 查看周边设施；进入行程可视化比较住宿、可达范围和出行方式。
4. 打开路线规划，核对起终点、分段走法、沿线服务及天气推演。
5. 也可以在 AI 辅助出行中输入“帮我定位一个考点”“从酒店到考点，优先公共交通”等指令。

不填居住点时，可先比较周边住宿；填入居住点后，流程会优先规划“住处 → 考点”。

## 配置

### 百度地图 AK

地图能力使用百度地图 JavaScript API。自定义考点搜索、路网采样、路线和周边设施查询需要网络及可用的**浏览器端 AK**。可以在页面右上角“设置”中填写自己的 AK；项目代码中的配置入口为 `config/ak.js`。服务端 IP 白名单 AK 不能直接用于浏览器。

**公开仓库注意**：浏览器端 AK 本身会暴露给访问页面的人，应设置与部署域名相匹配的 Referer 白名单，并在百度控制台监控额度。不要提交服务端密钥、私人中转站密钥或不受限制的凭据。当前本地配置文件包含演示用浏览器端 AK；发布或复用前请检查授权范围，并按需替换或轮换。

内置案例使用预构建数据，便于快速体验；自定义考点会产生新的地点检索、地理编码及算路请求。项目的配额计数和缓存只反映**当前浏览器**的使用情况，不等同于百度控制台的实时余额。

### 可选 LLM

未配置模型时，对话窗口使用本地规则引擎，能识别有限的考点、起点、路线、天气和周边服务表达；遇到歧义会请用户确认地点。它不是通用聊天模型。

如需接入自己的模型，在右上角“设置”中填写 Base URL、API Key（服务商要求时）、模型名并选择接口风格。页面提供模型列表检索和连通性测试；是否能在浏览器直连取决于服务商的 CORS、鉴权和模型权限。项目不内置 LLM Key、模型额度或代理服务。

模型配置保存在浏览器当前会话的 `sessionStorage` 中。请求从浏览器直接发送到所填接口；在不受信任的部署环境中不要填写敏感凭据。“清空本轮”会清除对话，并尝试撤销**这轮对话**对前四步造成的变更，恢复到对话开始前的状态。

## 技术结构

```text
index.html          界面、工作流、本地规则引擎及可选模型接入
config/ak.js        百度地图浏览器端 AK 配置
src/baidu-map.js    百度地图适配、覆盖物、坐标转换与路线调用
src/quota.js        本地配额计数、缓存、限流与熔断
src/weather.js      Open-Meteo 实况、预报、历史气候和空气质量
data/regions.js     省市区选择数据
data/snapshot.js    可由 script 加载的内置演示数据
data/snapshot.json  内置演示数据的 JSON 副本
```

地图以百度地图 BMapGL 为底图。内置案例依赖预构建快照，新地点通过在线检索和多方向路网采样生成近似等时圈；公交范围使用距离圈，并非官方公交服务边界。路线规划页则以当前选择的起点、终点和路线为准。

天气数据来自 Open-Meteo。考试日在未来 15 天内优先使用逐小时预报；更远日期使用历史同日气候参考，**不等于未来当天的确定预报**。推演中的百分比主要来自降水概率或历史降水频率，不是雪、雾、雷暴、沙尘各自独立校准的概率，也不等于官方预警。

地图不可用时会显示 SVG 示意图，避免页面空白；示意图**不是实时道路或真实路线**。新地点也未必有已结构化的考场楼栋、指定校门和校区边界。正式考试请以准考证、当年考点公告和官方天气信息为准。
